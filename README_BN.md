# উইন্ডোজের জন্য English (Bangladesh) [`en-BD`]

🌐 **ভাষা / Language:** [English (Bangladesh) (README.md)](README.md) | **বাংলা (বাংলাদেশ)**

**[ekushey.org](https://ekushey.org)**-এর তৈরি একটি হালকা ও ওপেন-সোর্স উইন্ডোজ ইনস্টলার - যা **উইন্ডোজ ১০, উইন্ডোজ ১১ এবং উইন্ডোজ সার্ভার** (**x86, x64 এবং ARM64**)-এ **English (Bangladesh) [`en-BD`]** রিজিওনাল লোকাল যুক্ত করে এবং **US with Taka sign**-কে ডিফল্ট কীবোর্ড লেআউট হিসেবে সেট করে।

## সমর্থিত অপারেটিং সিস্টেম ও প্রয়োজনীয়

একটি মাত্র (ইউনিভার্সেল) ইনস্টলার (`en-BD-Setup.exe`) **x86 (৩২-বিট), x64 (৬৪-বিট) এবং ARM64** আর্কিটেকচার সমর্থন করে।

| অপারেটিং সিস্টেম | সমর্থিত সংস্করণ ও ন্যূনতম বিল্ড | মন্তব্য |
| :--- | :--- | :--- |
| **Windows 10** | **Version 1903 (OS Build 18362)** থেকে **Version 22H2 (OS Build 19045)** | `.NET Framework 4.8` ইনস্টল করাই থাকে। পুরনো বিল্ডে (1607-1809) আগে `.NET Framework 4.8` ইনস্টল করে নিতে হবে। |
| **Windows 11** | **সব সংস্করণ** - **21H2, 22H2, 23H2, 24H2, 25H2, 26H1, 26H2** (x64 ও ARM64) | কোনো বাড়তি কিছু ছাড়াই সরাসরি চলবে। |
| **Windows LTSC** | **Windows 10 Enterprise LTSC 2021** (Build 19044)<br>**Windows 11 Enterprise LTSC 2024** (Build 26100) | সরাসরি সমর্থিত। *(Windows 10 LTSC 2019 / Build 17763-এ আগে `.NET Framework 4.8` ইনস্টল করতে হবে।)* |
| **Windows Server** | **Windows Server 2022** এবং **Windows Server 2025** | সরাসরি সমর্থিত (GUI এবং Server Core-এ `/install` সুইচসহ)। *(Server 2016 ও 2019-এ আগে `.NET Framework 4.8` ইনস্টল করতে হবে।)* |

- **অনুমতি:** অ্যাডমিনিস্ট্রেটর অনুমতি (স্বয়ংক্রিয়ভাবে চাইবে)।
- **রানটাইম:** উইন্ডোজ ১০ (১৯০৩+) ও উইন্ডোজ ১১-এর বিল্ট-ইন **`.NET Framework 4.8`** ব্যবহৃত হয়েছে। আপনি যদি পুরনো Windows 10, LTSC 2019 বা Windows Server 2016/2019 ব্যবহার করেন, তবে আগে **[Microsoft .NET Framework 4.8 Runtime](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48)** ডাউনলোড করে ইনস্টল করে নিন।

## বিশেষ সতর্কতা
> **ইন্টারনেট সংযোগ প্রয়োজন:**
> প্রথমবার ইনস্টলের সময় Windows Update থেকে Microsoft-এর `en-GB` ডিসপ্লে ল্যাঙ্গুয়েজ প্যাক ডাউনলোড করতে সক্রিয় ইন্টারনেট সংযোগ প্রয়োজন। ইন্টারনেট না থাকলে সিস্টেমের কোনো সেটিং পরিবর্তন না করেই ইনস্টলার নিরাপদে বন্ধ হয়ে যাবে।

> **Windows SmartScreen সতর্কবার্তা:**
> ওপেন-সোর্স কোড সাইনিং সার্টিফিকেট পাওয়ার আগ পর্যন্ত রিলিজ ফাইলগুলো বর্তমানে আনসাইন্ড (unsigned) অবস্থায় রয়েছে। Windows SmartScreen সতর্কবার্তা দেখালে `.sha256` চেকসাম মিলিয়ে **More info → Run anyway** ক্লিক করুন।

> **Windows Home Single Language ব্যবহারকারীদের জন্য:**
> Windows Single Language সংস্করণে অপারেটিং সিস্টেমের ডিসপ্লে ল্যাঙ্গুয়েজ পরিবর্তন বা মুছে ফেলা যায় না। এই ইনস্টলারটি আপনার উইন্ডোজের ডিসপ্লে ল্যাঙ্গুয়েজ বা সিস্টেম লোকাল পরিবর্তন করে না - বরং নিরাপদভাবে **`en-BD`** রিজিওনাল ফরম্যাট (`৳`, লাখ/কোটি, `DD/MM/YYYY`, মেট্রিক, A4) এবং **US with Taka sign** কীবোর্ড লেআউট যুক্ত করে।

> **বাংলাদেশের বাইরের ব্যবহারকারীদের জন্য:**
> এই প্যাকেজটি বাংলাদেশের স্থানীয় মানদণ্ড অনুযায়ী সেট করা - বাংলাদেশি টাকা (`৳` / `BDT`), **লাখ ও কোটি** (`1,00,000.00`) সংখ্যা বিন্যাস, **`DD/MM/YYYY`** তারিখ, **রবিবার** থেকে সপ্তাহ শুরু, **A4** কাগজ এবং **`Shift + 4` = `৳`** (`$`-এর জন্য `AltGr + 4`)। আপনি যদি বাংলাদেশের বাইরে বসবাস করেন অথবা `Shift + 4`-এ `$` এবং পশ্চিমা `100,000.00` সংখ্যা বিন্যাস চান, তবে আপনার দেশের নিজস্ব উইন্ডোজ লোকাল (যেমন `en-US`, `en-GB`, `en-CA`, বা `en-AU`) ব্যবহার করুন।

## ইনস্টল করার নিয়ম

১. **[Releases](../../releases)** পাতা থেকে **`en-BD-Setup.exe`** ডাউনলোড করুন।
২. **`en-BD-Setup.exe`** চালু করুন এবং অ্যাডমিনিস্ট্রেটর অনুমতি দিন।
৩. **Install** বাটনে ক্লিক করুন।
৪. ইনস্টলেশন শেষে উইন্ডোজ **রিস্টার্ট (Restart)** করুন (অথবা সাইন-আউট করে আবার সাইন-ইন করুন)।

## আনইনস্টল ও পূর্বাবস্থায় ফেরানো

১. **Settings -> Apps -> Installed apps** (অথবা **Control Panel -> Programs and Features**)-এ যান।
২. **English (Bangladesh) Setup** খুঁজে **Uninstall**-এ ক্লিক করুন।
৩. উইন্ডোজ রিস্টার্ট বা সাইন-আউট করলে আপনার আগের সেটিংস ফিরে আসবে।

*(অ্যাডমিন ডিপ্লয়মেন্টের জন্য: `en-BD-Setup.exe /install` এবং `en-BD-Setup.exe /uninstall`।)*
